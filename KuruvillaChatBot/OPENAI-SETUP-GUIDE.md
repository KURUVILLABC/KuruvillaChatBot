# 🤖 OpenAI Integration Setup Guide

The digital twin chatbot has been configured to use **real OpenAI API** for generating contextually-grounded responses based on your knowledge base.

## ✅ What's Been Done

1. ✅ Installed OpenAI SDK (`npm install openai`)
2. ✅ Created `OpenAIProvider` class with knowledge base grounding
3. ✅ Updated configuration to support OpenAI provider
4. ✅ Updated server to instantiate OpenAI when configured

## 🔑 Step 1: Get Your OpenAI API Key

1. Go to: **https://platform.openai.com/api-keys**
2. Click "Create new secret key"
3. Copy the key (format: `sk-...`)
4. **Keep this private** - never commit to git!

## 📝 Step 2: Update .env File

Open `.env` in the project root and update:

```env
# Change this line:
AI_PROVIDER=mock

# To:
AI_PROVIDER=openai

# And add your API key:
OPENAI_API_KEY=sk-your-actual-key-here
```

**Example:**
```env
AI_PROVIDER=openai
OPENAI_API_KEY=sk-proj-abc123xyz789...
```

## 🔄 Step 3: Restart Backend Server

The backend server will automatically reload with the new configuration.

If it doesn't auto-reload:
1. Stop the current backend server (Ctrl+C in terminal)
2. Run: `npm run dev` (in the `backend/` folder)
3. You should see: `[CONFIG] AI running in OPENAI mode`

## ✨ Step 4: Test in Browser

1. Open http://localhost:5173 in your browser
2. Try asking a question:
   - "Tell me about your projects"
   - "What are your main skills?"
   - "What excites you about AI?"

3. You should now see **real AI-generated responses** that are:
   - ✅ Grounded in your knowledge base
   - ✅ Naturally written by the LLM
   - ✅ Speaking as the actual person (first-person)
   - ✅ Unique and contextual for each question

## 🔍 What's Happening Behind the Scenes

When you ask a question:

```
1. Frontend sends message to /api/chat
   ↓
2. Backend builds system prompt with knowledge base context
   ↓
3. System prompt includes:
   - WHO YOU ARE (digital twin persona)
   - YOUR EXPERIENCE (from knowledge base)
   - YOUR PROJECTS (from knowledge base)
   - YOUR SKILLS (from knowledge base)
   - YOUR EDUCATION (from knowledge base)
   ↓
4. Backend sends to OpenAI API with system prompt + question
   ↓
5. OpenAI generates response using your knowledge as context
   ↓
6. Response returned to frontend and displayed in chat
```

## 🎯 Key Differences: Mock vs OpenAI

### MockAIProvider (Development)
- Pre-written response templates
- Keyword-based routing
- Consistent, deterministic
- No API cost
- Good for testing

### OpenAIProvider (Production)
- Real AI-generated responses
- Context-aware and natural
- Unique responses each time
- Uses your knowledge base for grounding
- Small API cost per request (~$0.001 per message)

## 🛠️ Troubleshooting

### "OpenAI API key is required"
- Make sure `.env` has: `OPENAI_API_KEY=sk-...`
- Make sure it's set BEFORE starting server
- Restart the backend server

### "API rate limit exceeded"
- You're making requests too quickly
- OpenAI has rate limits on free accounts
- Wait a minute before retrying
- Consider upgrading your OpenAI account

### "Invalid model: gpt-4-turbo-preview"
- Your account may not have access to GPT-4
- Edit `backend/src/providers/ai.ts` line 210
- Change `model: 'gpt-4-turbo-preview'` to `model: 'gpt-3.5-turbo'`
- Restart server

### Server won't start
- Check backend console for error messages
- Ensure .env file is properly formatted
- Make sure there are no extra spaces in API key
- Verify openai package is installed: `npm list openai`

## 💰 Costs

OpenAI API pricing (approximate):
- GPT-4 Turbo: ~$0.03 per 1K prompt tokens, $0.06 per 1K completion tokens
- GPT-3.5 Turbo: ~$0.0005 per 1K prompt tokens, $0.0015 per 1K completion tokens

Each message typically uses 500-1500 tokens total, so costs are minimal for testing.
